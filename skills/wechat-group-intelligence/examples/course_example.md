# 课程群示例

This fictional example demonstrates evidence shape. It is not a fixed answer template.

## 输入节选

```text
2026-09-08 09:00 王老师
第三节的自动化我还是不会操作，跟不上。

2026-09-08 09:05 李老师
我把课堂方法用到周报里了，以前两小时，现在大约四十分钟。

2026-09-08 09:10 张总
我们团队也需要这种培训，下个月能不能安排？
```

## 合格输出节选

### 发现：课程同时出现操作障碍与企业培训需求

#### 事实

一名学员明确表示第三节自动化操作跟不上；另一名成员报告周报处理时间缩短；一名成员询问下月团队培训。

#### 证据

- 王老师，09:00：“第三节的自动化我还是不会操作，跟不上。”
- 李老师，09:05：“以前两小时，现在大约四十分钟。”
- 张总，09:10：“我们团队也需要这种培训，下个月能不能安排？”

#### 推断

课程存在需要补强的操作教学环节；李老师的结果是个人自报，尚未独立验证；张总表达了明确团队培训需求，但其采购角色和预算未知。

#### 对用户的影响

应同时处理学习体验和需求确认，不能把培训询问直接当作已成交商机。

#### 建议行动

24 小时内向王老师确认具体卡点并提供操作示例；向张总确认人数、目标、预算流程和期望日期。所有对外回复由用户审阅后发送。
