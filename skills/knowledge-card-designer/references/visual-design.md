# 视觉风格与提示词

基于内容与使用场景推荐三个明显不同的方向。以下是可组合的设计语言，不是固定模板。卡片始终 3:4，文字直接由生图模型融入画面。

## 六类风格

- **清晰教学型**：学习、概念和步骤；浅色或柔和渐变背景，深色文字和一两种强调色；标题、说明、图解分区清楚，用编号、箭头和简洁示意图表达关系，避免课件式密集堆字。
- **编辑杂志型**：观点、文章精华；纸感或低饱和背景，大标题、留白与不对称网格相互平衡；少量主题摄影感插画或抽象形状，避免装饰挤占正文。
- **图解插画型**：机制、关系、故事；淡色或简化场景为底，将概念变成可理解的对象和关系图，标签紧邻对应对象，视觉路径明确，不制造错误因果。
- **手绘笔记型**：复习、经验；暖白纸纹或淡网格，手绘线条、便签、标记与小插画有节制地组织重点，文字区域干净，手写感不以牺牲辨识度为代价。
- **商务专业型**：企业培训和管理；低饱和背景、克制的品牌感配色，几何分区、对比模块、编号和简单图标，信息层级严谨，避免无意义图表或虚构数据。
- **活泼创意型**：轻科普、分享；明快但协调的颜色、灵活色块与主题角色或贴纸，适度变化构图，文字对比度和留白优先，不以热闹遮挡知识。

根据概念、流程、分类、对比、因果、观点论据或注意事项安排相应的分区与阅读路径。背景可用渐变、纸纹、几何或相关场景，不能妨碍文字；装饰应解释知识、引导视线或烘托氛围，不能无关堆砌。照顾标题安全边距，避免裁切；复杂表格换成容易读懂的模块，不遗漏行或条件。

## 每张生图提示词

以当前工具支持的格式，明确写出：
1. 用途、受众和本张知识目标。
2. 3:4 竖版、选择的风格与系列共同视觉语言。
3. 要精确呈现的完整标题、正文、标签、数字、必要来源；明确文本原文，禁止自行增加或改写关键事实。
4. 构图、标题位置、信息模块、知识关系与阅读顺序。
5. 背景颜色、材质、场景与文字阅读区。
6. 与主题有关的插图、装饰、位置和作用。
7. 配色、文字层级、对比度、留白和安全边距。
8. 防止错字、漏项、裁切、遮挡、无关装饰与拥挤；不支持的功能不编造参数。

用户参考图与品牌要求融入上述字段；没有要求时不要虚构品牌。完成后将图片逐项对照已确认文字和知识结构检查，而不是只检查美观。
