# 输出路由与品牌确认

在用户确认“直接开始生成”后，依次确认以下信息；一次只问一个缺失项。

1. **输出形式**：聊天版、Markdown、Word、HTML；若未选，问“你希望先在聊天中查看，还是直接生成 Markdown、Word 或 HTML？”
2. **品牌化**：问“是否需要加入企业名称、Logo、品牌色或品牌规范？”
3. **现成模板**：问“是否有需要沿用的 Word 或 HTML 模板？”

## 路由规则

| 选择 | 动作 |
|---|---|
| 聊天版 | 在对话中输出客户版课程方案。 |
| Markdown | 输出可保存的 Markdown 文案。 |
| Word，无新模板 | 使用 [course-outline-reference-template.md](course-outline-reference-template.md) 指定的保留参考文件副本创建；保留其视觉系统，替换所有客户事实，并将正文和表格单元格设为 1.5 倍行距。 |
| Word，有模板 | 先读取模板；保留其视觉系统和结构，再输出。 |
| HTML，无模板 | 以无品牌响应式 HTML 咨询方案模板输出。 |
| HTML，有模板 | 先读取模板，再在其结构和样式系统中输出。 |

用户提供 Logo、品牌色、品牌规范或模板时，说明将使用哪些资产；未提供新的 Word 模板时，明确采用当前课程大纲参考模板。用户后来提供的模板是当前交付物的设计权威，不得被参考模板覆盖。
