# Training Brief 字段说明

将信息归入下列字段；缺失项保留为空，不要编造。

| 字段 | 说明 |
|---|---|
| customer_name | 客户名称；不明可省略 |
| industry_and_context | 行业、组织背景、业务变化 |
| target_learners | 角色、人数、管理层级、典型工作情境 |
| learner_baseline | 相关经验、工具基础、常见阻碍 |
| stated_topics | 客户明确提出的主题或工具 |
| business_problem | 希望改善的实际工作问题 |
| desired_outcomes | 培训后学员能完成的行为、产出或变化 |
| duration | 天数、起止时间、休息安排 |
| delivery_mode | 线上、线下、混合；是否已确定 |
| practice_design | 是否实操、使用统一案例或真实业务材料 |
| available_materials | 模板、制度、数据、旧课件、真实案例 |
| constraints | 合规、保密、设备、软件、预算、时间等限制 |
| confirmed_facts | 客户直接提供、可引用的事实 |
| assumptions | 为推进设计所作的暂定判断 |
| open_questions | 会改变目标、难度、结构或交付的关键问题 |

关键补问优先级：先问目标成果，其次问学员基础与时长，再问交付方式、实操条件和可用材料。一次最多提出三项。
