# 朋友圈文案撰写

**先判断受众，再把真实想法写成自然、有层次、可直接发布的朋友圈文案。**

![Version](https://img.shields.io/badge/Version-0.1.1-9f6b13)
![Language](https://img.shields.io/badge/Language-中文-2f7a65)
![License](https://img.shields.io/badge/License-UNLICENSED-6e7781)

</div>

> **定位**：根据主题、观点、素材或初稿，撰写可直接复制的朋友圈文案。<br>
> **不做什么**：不生成图片或配图方案，不编造个人经历、客户案例或效果数据。

## 为什么需要它

同一个想法，写给企业管理者、个人 OPC 或更广泛的人群，切入点可能完全不同。这个 Skill 会先判断内容面向谁，再根据材料展开，不要求每条朋友圈套用固定长度和结构。

## 快速开始

将本目录复制到 Codex Skills 目录，然后在请求中提供主题、观点、素材或初稿：

```bash
cp -R skills/moments-content-automation "${CODEX_HOME:-$HOME/.codex}/skills/"
```

例如：

```text
用 $moments-content-automation，根据下面这段想法写一条朋友圈：……
```

输出是一条单独的朋友圈文案，保留适合手机阅读的换行与分段，可直接复制。

## 工作原理

1. 判断用户明确指定或素材自然指向的受众；没有明显倾向时，围绕共同问题面向更广泛的人群。
2. 找出这条内容最重要的表达目的，并区分已知事实、观点、计划和未知信息。
3. 按素材本身组织内容，不强制字数、段数、开头或结尾模板。
4. 用自然口语表达，并按语义分段；不同想法之间留空行，便于手机阅读。
5. 对照硬性要求复核受众、原意、事实依据和复制格式；不通过就修改。再检查内容层次、口语感、分段和结尾，有明显问题时继续打磨。

## 核心能力与适用场景

- 从主题、观点、课程片段、案例素材、产品想法或现有初稿撰写或改写朋友圈。
- 受众判断支持企业端、个人 OPC 端和没有明显倾向的广泛人群。
- 企业与 OPC 确有共同议题时，可以围绕共同问题表达；需求分歧明显时，不强行拼在一起。
- 篇幅和结构随内容变化；复杂内容可以充分展开，简单观察可以保持简洁。
- 文案优先使用自然口语、具体表达与有呼吸感的分段，减少套话和明显 AI 腔。

## 示例

```text
输入：很多人听到“一人公司”，会以为所有事情都要一个人扛。真正成熟的状态，是借助工具、流程和协作，把精力留给只有自己能做的事。

输出：
很多人听到“一人公司”，
会以为所有事情都要一个人扛。

但真正成熟的状态，
不是把自己塞进每个环节，
而是学会借助工具、流程和协作，
把精力留给只有你能做的事。

一个人也可以走得很稳，
前提是，不再只靠硬撑。
```

## 输入与输出

| 类型 | 内容 |
| --- | --- |
| 输入 | 主题、观点、素材、课程片段、案例、产品想法或朋友圈初稿；可选受众和语气要求 |
| 输出 | 一条或用户明确要求的多条朋友圈文案，保留自然分段与换行 |

## 隐私与边界

- 只把用户提供或明确授权读取的材料作为文案依据。
- 不虚构作者经历、客户对话、情绪、成果、数字或评价。
- 材料无法支撑某项说法时，先询问补充信息，或只写材料能够支持的内容。
- 文案中的示例只用于说明写法，不表示真实发生过。
- 本 Skill 不生成图片、图片提示词、海报或视觉方案。
