# 视觉系统

生成底图时读取本文件。目标是系列稳定、每日构图有新鲜感，而不是逐像素套模板。

## 固定骨架

| 元素 | 规则 |
|---|---|
| 画布 | 1024×1536 PNG，2:3 竖版 |
| 气质 | 暖象牙白/米白纸张、柔和晨光、克制金色；高级商业杂志与现代知识品牌感 |
| 日期卡 | 右上安全区，米白纸卡、轻阴影、两个金色图钉；星期与 `YYYY.MM.DD` 清晰准确 |
| 人物 | 从人物资产池按主题选择；可位于左、右、中央、近景或半身，姿态、表情和造型服务当天观点，不锁定下半区偏右 |
| 服装与袖子 | 保持正常穿着逻辑：西装/外套不披肩悬挂，双侧可见袖子、肩线、袖缝和袖口连续自然；不得出现断袖、消失袖、重复袖、错位袖或袖子与手臂不合理拼接 |
| 二维码区 | 左下真实资产区域 `x=28, y=1260, 224×224`；底图须遵守[底部安全区合同](layout-contract.json)中的保守净空范围 |
| Logo 区 | 右下真实资产区域由本机配置决定；底图须遵守[底部安全区合同](layout-contract.json)中的保守净空范围，并与二维码形成同一底部视觉带 |
| 人物标签 | 文案固定为 `谷燕燕` 与 `AI + OPC 实战导师`，但位置跟随人物轮廓：可在肩侧、座椅侧、人物留白侧或人物近旁；保持双列竖排与一根细金色竖线，不遮挡脸、手或正文 |

## 文字层级

1. 主标题 12–22 个汉字、两行内；清晰、有力度的中文手写或毛笔字，先读到。标题位置服从人物与结构，不默认放在上方。
2. 星期标签使用细衬线大写英文与高字距，例如 `WEDNESDAY PRACTICE`。
3. 中文正文为细宋/明朝体，2–3 行，行距舒展。
4. 英文点缀短、自然、清晰，不做逐字硬译。
5. 画面只出现内容包锁定的文字。辅助纸张、书本、墙面和道具使用无字纹理或抽象笔触；正文、英文与标题可分布在人物两侧、下方或结构图的留白中，但必须形成清晰阅读路径。

## 动态构图选择

每张日签先选择一个与主题和人物资产匹配的构图路线，再安排文字；“随机”是受控变化，不是任意堆放。优先选择与近几张不同的路线：

1. **人物单侧**：人物在左或右，标题与正文在对侧，以留白形成对读。
2. **人物近景**：脸部或半身成为视觉核心，标题绕人物轮廓展开，正文置于清晰留白。
3. **结构叙事**：用阶梯、卡片、矩阵、循环、坐标、路径、模块或流程图，把当天观点可视化；结构必须解释观点，而不是纯装饰。
4. **分栏杂志**：用纸张、窗格、边线或块面形成阅读分区，人物与文字跨栏呼应。
5. **插画转场**：仅在选用插画资产时使用水彩笔触、色块或局部抽象化，保留正文的清晰度。

日期卡、二维码和 Logo 不参与随机排版；其余元素允许移动，但不得侵入这三类安全区，也不得遮挡人物面部、手部或关键文字。

## 底部安全区合同

在生图前读取 [`layout-contract.json`](layout-contract.json)。它定义了两块**保守净空范围**：左下二维码净空区与右下 Logo 净空区。其目的不是画出两个底框，而是给最终的真实素材留出呼吸空间。

- 两区及其之间的底部自然带只使用连续的纸张纹理、柔和光影或极轻的水彩质感；不得出现硬边矩形、白框、色块、卡片或“预留位”视觉痕迹。
- 净空区内不得出现人物轮廓、头发、手、衣物、座椅/书本/植物等道具、结构图、正文或英文；二维码和 Logo 也不得在底图阶段生成。
- 人物可向底部渐隐，但必须在二维码净空区的上方结束；不能依靠“透明水彩边缘”规避该要求。
- 用真实二维码和 Logo 合成后再检查；如果资产压住人物或关键文字，重生底图，不移动固定资产去迁就底图。

## 每日变化

让人物动作、表情、服装造型、光影和结构图共同服务当天观点。例如：行动可用前倾/手势，复盘可用翻阅资料，判断可用思考近景，能力产品化可用模块或卡片，连接可用温和侧身。先依据人物参考的已有姿态选择构图，再要求生图模型延续或合理变化动作；不要为了套版强行改变人物。

同一周内不重复核心视觉隐喻。优先使用纸张、光线、路径、种子、阶梯、窗口、书页等人本元素；不使用机器人、电路板、大面积黑底、霓虹、重赛博或廉价培训海报语言。

## Imagegen 底图合同

在提示中逐字列出日期、星期、主标题、标签、正文、英文和人物介绍，并声明它们是唯一允许出现的文字。先在提示中明确本张选择的人物资产、构图路线、人物位置、各文字区与人物标签的相对位置；不要默认把标题和正文集中在顶部。人物参考图只用于身份保持，输入图中的棋盘格必须完全替换为新场景。提示必须同时明确：人物外套按正常方式穿着，双侧可见袖子与肩线、袖缝、袖口及手臂连接完整自然；不允许披肩悬挂、断袖、消失袖、重复袖或衣物与肢体错位。

底图必须逐项带入 [`layout-contract.json`](layout-contract.json) 的底部自然带和两块净空范围：二维码和 Logo 后续以原始素材叠加，绝不由生图模型绘制。提示应明确要求“连续自然背景、无矩形占位框”，并列出净空区禁止的人物、手、衣物、道具、文字和伪资产。

### 水彩转场路线

当且仅当选中插画人物资产或当天观点适合“行动后的迭代、转向、新局”时，可使用水彩转场路线：人物保持左/右单侧或上半身构图；以低饱和蓝色水彩和克制金色路径表达从模糊到清晰的推进；标题置于人物对侧中段，正文与英文分开形成阅读节奏。水彩笔触是结构，不得替代底部净空，也不得降低正文清晰度。
