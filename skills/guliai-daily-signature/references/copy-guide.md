# 日签与朋友圈文案

## 海报内容包

| 字段 | 要求 |
|---|---|
| 主题 | 一个清晰判断，不混写多个理念 |
| 主标题 | 12–22 个汉字，两行以内；有行动感、可读、可记 |
| 星期标签 | 大写英文，2–3 个词，与当天语气匹配 |
| 中文正文 | 2–3 行，每行约 10–18 字；补充主标题，不重复堆砌 |
| 英文点缀 | 一句自然短句；服务语气，不做生硬逐字翻译 |
| 人物介绍 | 固定为 `谷燕燕` 与 `AI + OPC 实战导师` |

姓名、日期、数字、专有名词和用户指定原句逐字锁定。没有依据的经历、身份、数据、成绩、客户评价和“今天发生了什么”不进入内容包。

## 朋友圈正文

正文为 80–130 个可见字符，使用自然的个人观点口吻。推荐节奏：观察或感受 → 判断展开 → 行动或开放式收束。

- 同一个观点、同一组递进关系连续分行。
- 语义转换、层次推进或进入收束时空一行。
- 形成 2–5 个自然段；手机阅读既没有文字墙，也不机械地一句一段。
- 与海报同主题但不逐句复述。
- 默认不使用表情符号、话题标签、联系方式、营销口号或强制互动。

## 纯文件合同

`朋友圈文案.md` 只保存正文：第一行直接是正文，最后一行停在正文最后一句。文件不含 YAML、Markdown 标题、日期、星期、主题、海报名、来源、字数、生成说明或发布提示。用户打开文件后全选即可直接复制发布。
