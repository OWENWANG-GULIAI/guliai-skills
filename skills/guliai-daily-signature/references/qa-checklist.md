# 最终验收

按顺序检查；全部通过才可运行 `publish`。

## 底图目视检查

- 日期与星期匹配，格式为 `YYYY.MM.DD`；日期卡有且只有两个图钉。
- 主标题、星期标签、中文正文、英文、`谷燕燕`、`AI + OPC 实战导师` 逐字正确。
- 主标题为清晰手写体；正文为细体且行距舒展。
- 人物身份可信，脸部、手部和动作自然；约占画面 1/3，不遮挡文字。
- 服装穿着逻辑正常：外套不是披肩悬挂状态；双侧可见袖子、肩线、袖缝和袖口连续自然，与手臂连接合理。出现断袖、消失袖、重复袖、错位袖或衣物与肢体拼接异常，均视为底图失败。
- 人物标签是两列竖排，两列之间只有一根细竖线；标签贴近人物轮廓或人物留白侧，不固定在单一画面坐标，且不遮挡脸、手或正文。
- 主标题、正文和英文已按人物姿态与构图路线分布；不应机械地全部集中在上方。阅读顺序清晰，文字不压住人物面部、手部、日期卡、二维码或 Logo 安全区。
- 结构图（如路径、卡片、矩阵、阶梯、循环、坐标或流程）必须与当天观点有关，并服务阅读路径；没有必要时不强行添加。
- 辅助道具无额外文字；画面无伪二维码、伪 Logo、二维码框或水印。
- 对照 [`layout-contract.json`](layout-contract.json) 检查左下二维码与右下 Logo 的保守净空范围：其中没有人物轮廓、头发、手、衣物、道具、结构图或文字；人物在二维码净空区上方结束，不能只留下淡化的衣物边缘。
- 底部自然带连续且无硬边矩形、白框、色块、卡片或“预留位”痕迹；画面无伪二维码、伪 Logo 或生成的品牌字标。

底图失败时只保留成功约束并定向重生完整底图。服装或袖子失败时，重生提示必须明确要求正常穿着、双袖完整和手臂连接合理。最多自动返工两次；仍失败则展示当前最好预览并说明失败项，不替换正式文件。

## 合成后目视检查

- 海报为 1024×1536 PNG，缩略图先看到主标题，再看到人物与观点。
- 二维码位于左下，Logo 位于右下，处在同一底部视觉带；无遮挡、无拉伸、无额外底框，也不压住人物、衣物或文字。
- Logo 形状、字标、颜色和留白与官方原图一致。
- 朋友圈正文与海报同主题，语义分段自然，可直接发布。

## 自动检查

运行：

```bash
python3 scripts/daily_signature_ops.py validate \
  --poster /path/to/staged-poster.png \
  --copy /path/to/staged-copy.md
```

通过条件：尺寸准确；文案 80–130 个可见字符、2–5 个自然段且无元数据/标题；海报中的二维码裁切像素哈希与源二维码最近邻缩放后的哈希一致。
