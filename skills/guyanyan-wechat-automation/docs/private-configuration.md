# 私有配置说明

公开仓库只提供可复用的工作流。下面资产和配置必须由每位使用者自行在本机提供，并始终保持在 Git 忽略目录或系统密钥链中。

## 写作资料库

`guyanyan-wechat-writer` 不内置任何真实写作资料。准备一个本机可访问的资料库，并至少包含：

- 写作口吻与常用判断；
- 目标读者描述；
- 可公开案例的证据状态与授权范围；
- 产品、课程或方法的真实资料。

在调用时明确告知 Skill 该资料库的范围；不要把未获授权的聊天、客户文件或学员信息作为公开文章依据。

## 视觉资产

如需使用固定个人介绍尾图、人物参考图或你的 Logo，请放在本机 `assets/local/` 或仓库外的私有路径，并明确每项素材的用途和公开授权。固定尾图必须在文章的最后一个内容块；若图中含客户 Logo、资质或个人信息，只有权利人确认可公开时才能用于文章和任何公开仓库。

## 公众号 API

发布到草稿箱需要公众号后台创建的 API 凭据，以及把实际发起 API 请求的出口 IP 加入公众号白名单。凭据应按 `baoyu-post-to-wechat` 的当前配置文档保存到其本机配置位置，例如 `.baoyu-skills/.env`；不要写入 Markdown、HTML、图片、日志或 Git 提交。

完整流程只创建草稿。群发、发布、定时发送和删除已有草稿始终应由人工在公众号后台决定。
