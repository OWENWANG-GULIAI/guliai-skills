# 公众号文章呈现

默认交付可复制 Markdown，排版服务于阅读节奏。

## 层级与信息组织

- 用一个 `#` 写文章标题。
- 长文、方法、案例复盘、教程和有多个论点的文章，用 `##` 切分主模块；需要拆解概念、步骤或场景时，用 `###`。
- 经历型或短观点文可以少用标题，保留自然段推进。
- 有先后顺序的动作写成 `1.` `2.` `3.`；并列要点使用 `-`。
- 需要对照、映射或前后变化时使用表格；单一观点不为形式加表格。

## 可复制内容

- 提示词、命令、代码、公式、路径和需要原样复制的流程放入 fenced code block，并在前面解释用途。
- 网址先写用途，再单独保留完整 `https://` 地址；不虚构链接。

## 内容经营与收尾

文章不必每篇成交，也不必强行加入 CTA。只有已有真实承接方式时，才自然邀请读者咨询、领取资料或参与产品。

可根据文章目的选用一种收尾动作：邀请读者留言真实问题、说明下一篇会持续拆解的主题，或在文章确实适合时邀请转发。
