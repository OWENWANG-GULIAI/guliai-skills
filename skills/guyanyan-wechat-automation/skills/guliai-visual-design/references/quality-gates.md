# 质量门槛

图像工具返回成功不等于成品通过。每张图都要检查实际输出，不能只看提示词。

## 硬失败

出现任一项不得交付：

- 指定姓名、日期、地点、价格、数字、单位或文案错误、缺失或被擅改；
- 用户提供的 Logo 缺失、明显变形、改色或裁切；
- 人物身份明显漂移，脸、手或身体结构异常；
- 流程箭头、对照、节点或数据关系错误；
- 文字不可读、主体被裁切、关键内容越出安全区；
- 只交付提示词，没有实际图片。

## 六维检查

| 维度 | 通过条件 |
|---|---|
| 事实 | 与用户输入逐项一致，无虚构补全 |
| 品牌 | 专业、清爽、现代、可信，有商业感与温度 |
| 信息 | 第一眼看懂主题，核心观点或卖点明确 |
| 视觉 | 层级、对齐、留白、对比、裁切与比例适合场景 |
| 创意 | 有记忆点但不模板化、不土味、不赛博滥用 |
| 素材 | 人物角色正确，Logo/二维码仅使用真实授权素材 |

每个成品最多两次自动定向返工。两次后仍有硬失败，应明确说明限制，不得把失败结果包装为已完成。
