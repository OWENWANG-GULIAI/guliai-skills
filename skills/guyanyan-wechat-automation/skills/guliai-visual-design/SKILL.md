# GULIAI 视觉设计

把文章中的关键关系转成可使用的最终图片。以品牌 DNA 稳定方向，以内容关系决定结构；不把每次生成锁进同一模板。

使用图像生成能力完成完整图片；人物、Logo 和其他资产仅在用户已提供、拥有使用权并且确实需要时作为参考图传入。不得把真实人物伪装为现场照片，也不得生成可用二维码。

## 运行合同

1. 从用户输入识别场景、主题、目标、受众、内容、数量、比例和素材意图。
2. 读取 [品牌 DNA](references/brand-dna.md)，根据场景选择结构化信息视觉、插画、摄影或纸张拼贴。
3. 先为每张图片写清它要帮助读者理解的关系，再生成；纯意境图不能充当文章配图。
4. 每张图独立生成并检查。发现错字、信息关系错误、人物肢体异常、Logo 变形或关键内容被裁切时，定向重做；最多两次自动返工。

## 默认方向

- 封面：公众号封面使用 2.35:1；主体、主标题和品牌识别放进中心安全区。
- 知识卡：一张只解释一个定义、对照、流程、判断或行动清单，卡片比例按版面决定。
- 人物：只在帮助解释行动或阅读方向时出现；动作、手势、目光与信息结构必须协调。
- 文字：明确层级、可在手机阅读；不要把正文缩小塞满图片。

## 最少追问

能从文章结构推断的内容直接执行。只有缺少的硬信息会导致虚假、不可用或无法满足明确条件时才提问；不编造日期、地点、价格、联系方式、业绩、资质、课程承诺或客户事实。

## 默认交付

- 返回实际生成的图片与稳定、可排序的文件名；
- 同时说明每张图对应的正文节点；
- 不交付只有提示词的半成品；
- 用户要求时再展示 VisualBrief、提示词或质检过程。
